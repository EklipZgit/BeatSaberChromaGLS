# ChromaGLS

**Requires [BeatToTheFuture](https://github.com/EklipZgit/BeatToTheFuture/releases).** so that mappers' ChromaGLS maps in V3 can still use V4 walls and VNJS. Install the release matching your Beat Saber version.

Custom RGBA colors for Beat Saber's Group Lighting System (GLS), with independent strobe colors, flexible strobe timing, RGB/HSV transitions, and per-light color distributions.

Works alongside Chroma and Heck. Use the release built for your Beat Saber version.

- **[Download](https://github.com/EklipZgit/BeatSaberChromaGLS/releases)** - install the matching release and its dependencies.
- **[Changelog](CHANGELOG.md)** - release history and upcoming changes.
- **[Using ChromaGLS](UsingChromaGLS.md)** - installation, settings, mapping examples, and the full property reference.
- **[Color and bloom guide](README-Colors.md)** - visual examples for balancing HDR color, alpha, brightness, and bloom.
- **[Building and contributing](BUILD.md)** - development setup, builds, tests, and implementation details.
